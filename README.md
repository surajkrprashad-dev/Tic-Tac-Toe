
# 🎮 Tic Tac Toe (React.js)

A simple Tic Tac Toe game built using React.js.

---

## 🚀 Features

- Two-player gameplay (X vs O)
- Winner and draw detection
- Restart game option

---

## ⚙️ Run Locally

```bash
git clone https://github.com/your-username/tic-tac-toe.git
cd tic-tac-toe
npm install
npm start
